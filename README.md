# 北陵 FIGHTERS

Phaser 3 / TypeScript / Viteによるローカル対戦格闘ゲーム。理科・数学・英語・社会・体育のドット絵アニメーションを実装しています。国語は原画の準備待ちです。

画面は960×540のアーケード画面としてウィンドウに最大表示します。縦横比を保つため、16:9以外では黒帯が付きます。青いキャラ選択画面、大きな左右ポートレート、顔アイコン、ドットフォント、黄色い体力バーへ変更。設定メニューは画面内、対戦時はマウスを動かすと下部に表示します。

近接は両者が移動しなければ2発目まで当たり、3発目は届かない間合いに調整しました。1発目は2発目の射程を残す小さな押し戻し（0〜22px）、2発目は80px。移動・ジャンプで攻防をリセット。ガードは22px、遠距離は80pxの押し戻しです。遠距離には「2発で無効化」の制限はなく、届く限り当たります。全キャラのジャンプを約184〜205px、横移動量を約288〜326pxへ変更し、相手の全身を越えて位置交換できるようにしました。4Fの踏み切りと6Fの着地、理科の垂直・前・後ろジャンプの姿勢切り替えを追加しました。

## 起動

```sh
npm install
npm run dev
```

表示されたlocalhostのURLをChromeまたはEdgeで開きます。配布用は `npm run build`、確認は `npm run preview`。`dist/` をHTTPSの静的ホスティングへ配置できます。外部CDNやオンラインフォントは使いません。

## 操作

| | 1P | 2P |
|---|---|---|
| 移動 | A / D | ← / → |
| ジャンプ | W | ↑ |
| しゃがみ | S | ↓ |
| 攻撃 | F | Enter |
| 一時停止 | Escape | Escape |

後退方向の入力中に地上攻撃を受けるとガード。画面端でも後ろ入力で成立します。空中・攻撃中・被弾硬直中はガード不可。空中攻撃もガード不可です。

歩行速度は従来の2倍（ジャンプの距離は維持）。パッドも下入力でしゃがみ、近接キャラはしゃがみ中の攻撃でスライドします。遠距離キャラは低い位置から通常の飛び道具を出します。空中で攻撃するとジャンプ攻撃になります。マイコンの攻撃コードは変更ありません。

被弾判定はキャラ・コマごとの体の点を結ぶ多角形です。元画像に合わせて個別に記録し、表示と同じコマ・倍率・足元位置・左右反転を使います。髪・帽子・武器・服の裾は除外し、服で隠れた体は手動推定。KO中は被弾判定なし。押し合い用の判定は別です。歩行アニメーションは移動速度と切り離し、前進・後退とも10fpsで再生します。

要件書4.2にはジャンプ攻撃（ガード不可）の記載があります。スライド攻撃は記載がなく、今回の追加仕様です。しゃがみはガード区別の説明に登場しますが、下入力の操作は今回追加しました。

「接続設定」でBluetoothゲームパッドを1P・2Pに割り当てます。十字キー／左スティックの左右で移動、上でジャンプ。斜め上で斜めジャンプ。標準マッピングのパッドを対象にしています。

キャラ選択画面でも左右で選択できます。未割り当てのパッドは、ボタンかスティックを操作した順に1P・2Pへ自動参加します（接続設定での手動割り当ても保持）。A / ×、X / □、Startで決定、B / ○で決定解除。両者の決定で対戦開始。未実装の国語と相手の選択キャラはスキップします。長押しは350ms後から120ms間隔で移動します。

- **デバッグ**（初期設定）：下ボタン（A / ×）または左ボタン（X / □）で攻撃。マイコンなしで両者を操作可能。
- **本番**：ゲームパッドの攻撃ボタンを無効化し、マイコンの攻撃入力を使用。
- Startで一時停止。キーボードは両モードで使用できます。接続やキャラ選択など画面操作にはマウスを使用します。

## USBマイコン

「USBコントローラーを追加」で6台を1台ずつ選択します。115200bps、UTF-8/ASCII、改行区切り。例：`{5:1}\n`。クォート付き `{"5":1}\n` も可。

| ID | キャラ | 攻撃 |
|---|---|---|
| 1 | 理科 | ビーカー・近接 |
| 2 | 数学 | 三角定規・投擲 |
| 3 | 国語 | 辞書・近接（素材待ち） |
| 4 | 英語 | 発音した単語・遠距離 |
| 5 | 社会 | 剣・近接 |
| 6 | 体育 | 旗から覇気・遠距離 |

1を受信するとそのキャラの攻撃を要求、0は何もしません。未選択キャラは無視します。ポートの接続順はキャラやプレイヤーに影響しません。1を毎回送れば毎回要求されますが、攻撃硬直とクールダウンで制限します。0から1へのエッジ検出ではありません。複数の1を同じ更新内に受信した場合は1回にまとめます。

切断・ウィンドウの非アクティブ化で対戦が一時停止します。接続設定で再接続し、対戦画面へ戻って再開してください。USBポート選択はブラウザの許可操作が必要です。

## 素材の確認と追加

「モーション確認」で全5キャラの動作を選択し、再生速度・左右反転・コマ送り・体の判定を確認できます。元絵は `characters/` に保持しています。素材一覧・生成プロンプト・追加手順は [docs/all-character-art.md](docs/all-character-art.md) を参照。

ゲーム設定は `src/character_stats.json`。国語はID 3を予約し、素材が届くまで選択不可です。各キャラに待機・前進・後退・ガード・しゃがみ・被弾・ジャンプ・地上攻撃・空中攻撃・KOを実装。近接はスライド、遠距離はしゃがみ攻撃もあります。生成した似たコマや最後の姿勢を再利用している動作があります。

## 検証

```sh
npm test
npm run build
# 開発サーバー起動中、Google Chromeがインストールされた環境
node tests/browser.mjs
node tests/menu.mjs
GAME_URL=http://127.0.0.1:5175 node tests/all-art.mjs
```

戦闘ルール・シリアルパーサーはNodeテスト、ブラウザの起動・操作・パッドとシリアルの模擬入力はPlaywrightで検証します。スクリーンショットは `test-results/` に保存されます。実機のBluetooth2台＋USB6台同時接続は別途確認が必要です。

描画・シーン・テクスチャ読み込みは [Phaser公式ドキュメント](https://docs.phaser.io/phaser/concepts/scenes) に沿い、戦闘は描画と独立した60Hz固定更新です。攻撃は発生10F・持続5F・硬直19F、受付間隔30F。バランス数値は初期値です。
